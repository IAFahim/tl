# Benchmark status

`Alpha` is the executable v1 benchmark project and the only benchmark project included in the current solution. Its verifier, BenchmarkDotNet configuration, final reports, and JIT assembly are release evidence for v1.0.0-alpha.1.

The other directories are frozen v0 research sources and measurements. They explain algorithms and rejected designs but target removed APIs, have no project files, and are not current executable benchmarks. Their results apply only to the commits and contracts named in their local reports.
