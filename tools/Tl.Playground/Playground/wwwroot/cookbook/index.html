tl cookbook

live recipes over the data-authored API — every panel below is the real playground playground

How this works

Each recipe embeds one iframe pointing at the playground with query parameters (crowd, pattern, loop, dir, play, scale, amountA, windowA, amountB, windowB). The app bakes the authoring JSON with the real TimelineBaker.BakeJson, plays it through TimelineSet.Gather(ids).Seek(positions, forward).Apply(effects), and resizes its host via a setHeight postMessage after every render. Edit the JSON box inside any embed — the bake and the columns update live.

Recipe 1 — a uniform crowd on a looping timeline

Recipe 2 — a staggered crowd

Rows spread across every tick of a looping two-clip timeline: forward, backward, and the exact A-B-A undo.

Recipe 3 — waves with blended windows

Overlapping clip windows produce a blended factor region; the strip shows it as a third color band.

Recipe 4 — finite timelines clamp

With loop:false rows reaching the end park (skipped) instead of wrapping — the clamp is visible per row.
