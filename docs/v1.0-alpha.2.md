# v1.0.0-alpha.2 candidate

Status: unreleased. The exact completion state lives in [release issue #11](https://github.com/IAFahim/tl/issues/11).

This candidate turns the alpha.1 C# runtime into the first compiler ecosystem slice. `Tl.CSharp` provides one-package installation, `Tl.Compiler` owns the language-neutral plan boundary, and `Tl.Gen.C` emits portable C11 with a versioned ABI. The application output retains only `Tl.Runtime`; generator, compiler, C backend, and Roslyn assemblies remain build tools.

Generated C# timelines now publish track, clip, region, static-data, and batch-capacity facts. The compiler writes a deterministic `TlGenCompile.report.txt` with every artifact's UTF-8 byte count and each timeline's shape. `Timeline.RegistryRetainedBytes` reports the actual unmanaged registry allocation. The C report records plan format, ABI version, source bytes, static bytes, runtime heap bytes, and playback and frame size and alignment.

The current C backend emits payload handles as instruction constants and owns no static data or runtime heap, so both reported byte counts are zero. Its header asserts the 12-byte, 4-aligned playback ABI and the 24-byte, 4-aligned frame ABI at C compilation time.

Generated batches accept at most 256 ticks and snapshot them into at most 1,024 bytes of stack storage. This makes execution stable when a tick span aliases writable output. Validation completes against that snapshot before callbacks, so engine rejection preserves playback and outputs. Forward, backward, and oversized alias receipts cover the contract.

The generated lifecycle check now tests the Started and Stopped flags in one mask. Three independent BenchmarkDotNet runs on the i9-14900K with .NET 10.0.12 measured the complete public scalar path at 1.383 ns/tick for the sequential sum and 2.188 ns/tick for sequential heterogeneous combat, with 0 B allocated. Random scalar paths measured 4.786 and 7.015 ns/tick. Linux PMU measurements recorded approximately 9.47 and 14.67 cycles for the two public sequential paths. The alias-safe batch implementation still requires its final rerun, so alpha.1 batch values are not relabeled as alpha.2 results.

The C backend now rejects invalid identifiers and symbol collisions, rejects null active contexts before callbacks, preserves the full 16-bit authored-track boundary, and passes strict GCC and Clang C11 executable receipts. Unity now has a dedicated C# 9 UPM runtime with unmanaged contexts, concrete Burst kernels, BlobAsset-compatible data, and an ECS sample. The preview lane passes EditMode, PlayMode, Burst AOT, a Standalone Linux player build, and zero-allocation receipts; Unity 6000.0 with Entities 1.4.3 remains the declared stable floor and a separate CI lane.

The candidate stays below the 200,000-byte production source-and-path limit. Final bytes, packages, NativeAOT outputs, coverage, checksums, commit identity, and performance artifacts will be recorded from the immutable tagged commit. The existing repository has no license declaration; NuGet publication remains blocked until the owner makes that explicit decision.

The [implementation plan](../plan.md), [API contract](v1.0-alpha-api.md), [completion checklist](v1.0-alpha-checklist.md), and [coordination contract](coordination.md) are the handoff documents for another machine.
