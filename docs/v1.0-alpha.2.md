# v1.0.0-alpha.2 candidate

Status: unreleased. The exact completion state lives in [release issue #11](https://github.com/IAFahim/tl/issues/11).

This candidate replaces the alpha.1 directional runtime-ID surface with generated typed signed seek. A partial `ITimeline` declaration produces its typed facade, timeline-owned `Playback<TTimeline>`, borrowed `Data`, explicit dynamic `DynamicData`, and deterministic execution kernel. `Start(gameTick)` anchors local position zero. `TrySeek(ref data, delta)` replays every crossed local frame in signed order.

`Tl.CSharp` remains the one-package C# installation. `Tl.Compiler` owns the language-neutral plan boundary. `Tl.Gen.CSharp` owns incremental C# discovery and emission from `src/Tl.Gen.CSharp`. Its `netstandard2.0` analyzer runs in normal and IDE builds, while its `net10.0` CLI remains available through the explicit `TlGenExport` target. The application output retains only `Tl.Runtime`; generator, compiler, C backend, and Roslyn assemblies remain build tools.

Generated C# timelines expose track, clip, region, static data, and dynamic registry facts. Roslyn owns normal generated sources and incrementally reuses structural candidate and environment results. The explicit export target writes deterministic source and `TlGenCompile.report.txt` artifacts and preserves their timestamps on content-cache hits. `Timeline.RegistryRetainedBytes` reports actual unmanaged registry storage.

The generated typed Sum path is below 3 ns per executed frame for every case in the 117-result signed-seek matrix on the reference i9-14900K and .NET 10.0.12. The dynamic scalar path is 6.95–8.36 ns for unit movement. A heterogeneous Combat callback measures 4.165 ns typed forward and 7.696 ns typed while alternating direction. All 135 BenchmarkDotNet results allocate 0 B. These measurements establish a typed Sum target and an honest callback-dependent physical floor. [Raw signed-seek evidence](../benchmarks/Alpha/results/signed-seek/README.md) retains all process medians, logs, environment, generated hashes, assembly, PMU counters, receipts, and limitations.

The runtime `Playback` and `Playback<TTimeline>` ABI is 16 bytes. `Frame` is 40 bytes on x64, derives direction from its reverse flag, and carries no redundant ordinal or active-count fields. ABI receipts freeze layout, offsets, modifiers, and borrowed ref safety.

`Tl.Gen.C` proves that the neutral compiler boundary supports another backend. Its independently qualified C ABI v2 provides signed seek, 16-byte playback and 40-byte frame layouts at 8-byte alignment, pre-effect failure atomicity, and overlapping context/playback/output support. It is an in-process native-endian ABI whose binary32 arithmetic follows the target's native evaluation and rounding. Unity has a separate C# 9 UPM runtime with unmanaged contexts, checked-in kernels, BlobAsset-compatible data, and an ECS sample. Unity 6000.7.0a5 passes EditMode, PlayMode, Burst AOT, a Standalone Linux player build, player-content checks, and zero-allocation receipts. Unity 6000.0 with Entities 1.4.3 remains the declared stable floor and was unavailable locally.

The final integrated source-and-path measurement will be recorded against the 250,000-byte cap before tagging. Generated application source, native code, retained registry data, and package artifacts are reported separately.

The tagged artifact workflow derives identity from the tag target, packs all five packages twice, normalizes container timestamps, and rejects any byte difference. It verifies the package graph, embedded-source symbol packages, package-only JIT and NativeAOT execution, and application-output isolation before writing the deterministic manifest and checksums. Final hashes are created only from the immutable tagged commit.

The repository has no license declaration. NuGet publication remains blocked until the owner makes that legal decision.
