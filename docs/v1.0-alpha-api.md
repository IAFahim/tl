# v1.0-alpha API contract

Status: v1.0.0-alpha.1 contract, 2026-09-10. This document does not describe the released v0.6 API.

See the [implementation plan](../plan.md) for measurement gates and [execution checklist](v1.0-alpha-checklist.md) for work status.

## Declaration and ownership

A top-level public readonly partial struct implements non-generic ITimeline and declares exactly one public static Define(scoped Builder builder). Installing the generator package and building the consuming project is sufficient. There is no handwritten source-item list, new Attack(), Compile(), InMemory(), or Bind() in this path.

The track owns its primary behavior. ITrack<TClip> identifies the closed clip contract and includes the blend requirement. The generator validates static Forward/Backward signatures; C# does not provide a single interface member that accepts arbitrary typed parameter lists.

The first parameter is in Frame<TTrack,TClip>, with TTrack equal to the declaring track type. Remaining parameters are a finite list of in/ref/out typed component values. No implicit conversions, boxing, dynamic arguments, object arrays, or params expansion are used to infer a data contract. Alpha component values and authored payloads are unmanaged; a context itself is a borrowed ref struct, not a blittable unmanaged value.

## Complete primary consumer

This sample uses the implemented alpha API and generated members.

```cs
using Tl;

public readonly record struct Pose(float X, float Y);
public readonly record struct AnimationSettings(float Weight);
public readonly record struct AnimationClip(float X, float Y);

public readonly record struct Health(float Value);
public readonly record struct DamageSettings(float Multiplier);
public readonly record struct DamageClip(float Amount);

public readonly partial struct AnimationTrack : ITrack<AnimationClip>
{
    public void Blend(
        in AnimationClip first,
        in AnimationClip second,
        float factor,
        out AnimationClip result)
    {
        result = new(
            first.X + (second.X - first.X) * factor,
            first.Y + (second.Y - first.Y) * factor);
    }

    public static void Forward(
        in Frame<AnimationTrack, AnimationClip> frame,
        in Pose currentPose,
        in AnimationSettings animationSettings,
        out Pose nextPose)
    {
        nextPose = new(
            currentPose.X + frame.Clip.X * animationSettings.Weight,
            currentPose.Y + frame.Clip.Y * animationSettings.Weight);
    }

    public static void Backward(
        in Frame<AnimationTrack, AnimationClip> frame,
        in Pose currentPose,
        in AnimationSettings animationSettings,
        out Pose nextPose)
    {
        nextPose = new(
            currentPose.X - frame.Clip.X * animationSettings.Weight,
            currentPose.Y - frame.Clip.Y * animationSettings.Weight);
    }
}

public readonly partial struct DamageTrack : ITrack<DamageClip>
{
    public void Blend(
        in DamageClip first,
        in DamageClip second,
        float factor,
        out DamageClip result)
    {
        result = new(
            first.Amount + (second.Amount - first.Amount) * factor);
    }

    public static void Forward(
        in Frame<DamageTrack, DamageClip> frame,
        in Health currentHealth,
        in DamageSettings damageSettings,
        out Health nextHealth)
    {
        nextHealth = new(
            currentHealth.Value - frame.Clip.Amount * damageSettings.Multiplier);
    }

    public static void Backward(
        in Frame<DamageTrack, DamageClip> frame,
        in Health currentHealth,
        in DamageSettings damageSettings,
        out Health nextHealth)
    {
        nextHealth = new(
            currentHealth.Value + frame.Clip.Amount * damageSettings.Multiplier);
    }
}

public readonly partial struct Attack : ITimeline
{
    public static void Define(scoped Builder builder)
    {
        var animation = builder.Track(new AnimationTrack());
        var damage = builder.Track(new DamageTrack());

        builder.Clip(animation, new AnimationClip(2f, 1f), 0u, 40u);
        builder.Clip(animation, new AnimationClip(6f, 3f), 20u, 60u);
        builder.Clip(damage, new DamageClip(10f), 10u, 11u);
        builder.Clip(damage, new DamageClip(20f), 40u, 41u);
    }
}
```

Both track and clip types are inferred and checked at each Clip call. Animation clips cannot be attached to the damage handle. The handle also carries authoring ownership; foreign/default handles are rejected. Track fields may carry immutable authored configuration, accessed through frame.Track. Mutable per-entity state belongs in the supplied references.

The example computes replacement outputs for illustration. A ref Health callback would instead accumulate directly into caller-owned Health. Neither form implies that visiting a damage clip once and visiting it repeatedly are equivalent; application behavior is explicit.

## Frame

| Member | Contract |
| --- | --- |
| Track | Read-only reference to the authored TTrack value |
| Clip | Read-only reference to one resolved TClip value, including any blend |
| Tick | Effective tick in the timeline's duration |
| State | Enter, Stay or Exit using the declared movement law |
| TrackIndex | Stable authored track-instance identity within the definition |

There is no Ordinal, Count or Active field. Active may name a future explicit query if needed; no such query is required for alpha. Internal traversal indices and counts are representation details, not automatically deletable.

Frame is a borrowed callback view, cannot outlive the callback, and is not an array/enumerable of tracks. A blend value remains alive until the callback returns. It must remain valid during a callback-triggered compacting GC. Public Frame readability does not justify materializing a large struct in every hot call; the private generated adapter and inlining strategy must be measured.

TrackIndex is 16 bits and follows the 65,536-instance limit, independently of the 256-kind limit.

## Generated Input and Output

The generator emits nested Attack.Input and Attack.Output along with Attack.Id. It derives the union of required external read slots and writable slots. A method-local out value uses an initialized caller output slot at the outer boundary, so gaps and rejected calls can preserve storage.

The generator must produce the constructor names used below. Names expose slots to the caller; they are not automatic edges between unrelated operations.

```cs
var currentPose = new Pose(0f, 0f);
var currentHealth = new Health(100f);
var animationSettings = new AnimationSettings(1f);
var damageSettings = new DamageSettings(1f);
var nextPose = currentPose;
var nextHealth = currentHealth;

var input = new Attack.Input(
    currentPose: in currentPose,
    animationSettings: in animationSettings,
    currentHealth: in currentHealth,
    damageSettings: in damageSettings);

var output = new Attack.Output(
    nextPose: ref nextPose,
    nextHealth: ref nextHealth);
```

No fixed two-in/one-out rule exists. Ref values belong to writable context storage, even when read before being updated. Inherited slots retain identity through Include. For repeated types, independent parameters are independent slots; the compiler must not assume two Health values belong to the same entity. An ambiguous graph produces a source diagnostic; it does not silently connect values because they have matching names or types.

Runtime compatibility allows extra supplied slots. It rejects missing, ambiguous, incorrectly typed or incorrectly permissioned slots before effects. A generated Attack context may serve a damage-only definition if there is a unique valid mapping of its Health/settings/output slots. It cannot serve a definition requiring an unavailable PhysicsMass.

Ref is an alias to storage. In does not freeze the underlying value against writes through another alias. For a snapshot, the caller explicitly copies the component value into separate storage. Passing a reference to an ECS copy only edits that copy; passing an approved ECS component reference edits the component. Do not retain contexts over structural changes, asynchronous suspension, or an ECS scheduling boundary. The alpha does not claim compatibility with the Unity compiler/Burst until a Unity-specific backend is verified.

## Public execution

The core methods infer generated context types through a static abstract protocol while their consumer spelling remains non-generic. Generated partial members stay in the consuming assembly.

```cs
ushort id = Attack.Id;

if (!Timeline.TryStart(id, 0u, out var playback))
    return;

if (Timeline.TryForward(
        id,
        in playback,
        10u,
        in input,
        ref output,
        out var nextPlayback))
{
    playback = nextPlayback;
    currentPose = nextPose;
    currentHealth = nextHealth;
}

var timelines = Timeline.All;

if (timelines[id].TryBackward(
        in playback,
        5u,
        in input,
        ref output,
        out var previousPlayback))
{
    playback = previousPlayback;
}

ReadOnlySpan<uint> ticks = [6u, 7u, 8u, 9u, 10u];

if (timelines[id].TryForward(
        in playback,
        ticks,
        in input,
        ref output,
        out var batchPlayback))
{
    playback = batchPlayback;
}

if (timelines[id].TryStop(in playback, out var stoppedPlayback))
    playback = stoppedPlayback;
```

Indexing returns a small value facade; validation belongs in Try operations so an invalid ID is a false result, not a surprise allocation or indexer exception. C# does not support a static type indexer: exact Timeline[id] spelling requires an instance variable named Timeline. Timeline.All[id] is the normal spelling.

TryStart failure initializes its out playback to default. Other Try operations return the incoming playback on engine-detected failure. Successful TryStop is idempotent for an already-stopped valid owner. Default/unstarted playback cannot execute. A valid empty batch preserves playback/output and runs no hooks; malformed IDs/context/lifecycle are still rejected consistently.

Batch calls reuse the same references. They do not copy outputs back into separate input storage. Consumer exceptions expose prefix effects. Pure engine validation for the complete batch precedes callbacks so a final tick that would overflow the cycle count cannot partially mutate outputs and then return false.

Compiled definitions expose no destroy or topology-mutation operation. Callers must synchronize concurrent writes to the same component storage and must not recursively execute with the same writable aliases. Read-only registry and definition data may be used concurrently.

## Before and After hooks

IHook is a marker for statically validated `Forward` and `Backward` methods. The builder registration chooses the phase; the method name chooses the movement direction. Hook parameters are the same generated `in`, `ref`, and `out` component slots used by tracks. Engine metadata is absent from this alpha hook contract.

```cs
public struct AnalyticsState
{
    public uint Completed;
    public bool LastWasBackward;
}

public readonly struct BeforeAnalytics : IHook
{
    public static void Forward(ref AnalyticsState analytics)
        => analytics.LastWasBackward = false;

    public static void Backward(ref AnalyticsState analytics)
        => analytics.LastWasBackward = true;
}

public readonly struct AfterAnalytics : IHook
{
    public static void Forward(ref AnalyticsState analytics)
        => analytics.Completed++;

    public static void Backward(ref AnalyticsState analytics)
        => analytics.Completed++;
}

public readonly partial struct ObservedAttack : ITimeline
{
    public static void Define(scoped Builder builder)
    {
        builder.Before<BeforeAnalytics>();
        builder.Include<Attack>();
        builder.After<AfterAnalytics>();
    }
}
```

ObservedAttack receives its own ID and generated contexts. Output additionally requires ref AnalyticsState. Adding analytics does not mutate Attack, magically extend a compiled caller's storage, or make an old context compatible with a new required slot. The application selects the extended definition and supplies the extra reference.

Before runs after engine validation and before work. After runs only after successful work. Both run on accepted gaps, so analytics reads caller-initialized/preserved outputs where no track produced a new value. If Before or a track throws, After is not a finally hook. Multiple registrations are explicit effects and are not deduplicated just because the hook type repeats.

Alpha Include decorates one base timeline. Outer Before hooks run before included Before hooks, then base tracks execute, followed by included After hooks and outer After hooks. Within a phase, registration order is stable in both movement directions. Loops and duration come from the base. Recursive inclusion and incompatible redeclaration are diagnosed.

## Build discovery and caching

The app references Tl.Runtime and the build-only generator package. Normal build discovery sees eligible ITimeline declarations and referenced track, clip, and component contracts. Users do not maintain source item lists. Partial declarations in different files work. Include and alternate-schema routing require every involved timeline definition to be source-visible in the current compilation because the generator flattens and routes their authored bodies. Definitions from a referenced assembly are not reconstructed in this alpha.

The cache covers normalized definitions, referenced operation/type contracts, generated slot layouts, includes/hooks, backend/profile, compiler/language options, defines, assembly references and generator version. Stable input preserves generated bytes and timestamps. Changed dependencies invalidate their dependents. Deleting the last declaration removes only unchanged generator-owned output. Project paths, shell quoting and locale do not alter semantic output.

Source payloads must belong to the supported declarative authoring subset. Unknown runtime values do not become constants. Unsupported authoring receives a clear diagnostic at its source. The build tool runs before C# source generators, so a timeline declaration produced by another generator cannot feed this pass in the same build.

## Runtime loading and modding boundary

The mandatory alpha path is named code-authored definitions and build-visible assets. Runtime component values remain dynamic without regeneration. If late topology loading is included, it needs a separate total, typed loading operation and immutable native ownership, while execution uses the same Timeline.TryForward surface. The old Build/InMemory/Compile choice is not reintroduced as the public model.

Built-in or build-time extension hooks can be emitted as direct calls. A published NativeAOT process cannot load arbitrary new managed assemblies. Runtime mods need an explicitly chosen native ABI, bytecode interpreter, or a JIT-hosted plugin path with its own performance and safety contract; none is silently claimed by IHook.

## Capacity and failure policy

- Timeline IDs: all 0–65,535 ushort values. A separate valid/live state exists.
- Local closed track/clip kind IDs: 0–255; counts use a type that can represent 256.
- Authored track instances: 0–65,535. A narrow kind ID never substitutes for an instance index.
- No Ordinal/Active stored in Frame. No hidden public zero-check entry point that accepts invalid handles.
- Fixed alpha lifetime: no ID reuse inside one registry lifetime. Loading exhaustion is a typed failure.
- Unknown/missing context compatibility rejects before any user callback. Unsupported authored contracts diagnose during build.
- User callbacks may throw; Try does not convert those exceptions into false or undo their effects.
- Library source/path budget stays below 200,000 bytes. Generated game code/data has a separate measured budget.

## Public-surface exclusions

Do not ship public manual Bind, runtime Compile selectors, normal-use InMemory terminals, standalone-operation Then chains, duplicate compiled/interpreted consumer interfaces, old Tracks enumeration views, scratch-buffer overload families, per-arity ITrack interfaces, reflection-driven field matching, attribute boilerplate for each input/output, or unmeasured unchecked shortcuts.

Compatibility is intentionally broken for the alpha. A migration document must name removals and show a complete compiled package-consumer example. The alpha version is not a stable 1.0 compatibility promise.
