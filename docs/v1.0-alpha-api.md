# v1.0.0-alpha.3 C# API

Status: release candidate contract, 2026-09-11. Alpha.3 is source- and binary-incompatible with alpha.2.

## Domain declarations

```cs
public interface ITimeline
{
    static abstract void Define(scoped Builder builder);
}

public interface ITimelineCatalog
{
    static abstract void Define(scoped CatalogBuilder builder);
}

public interface IBlend<TClip> where TClip : unmanaged
{
    void Blend(in TClip first, in TClip second, float factor, out TClip result);
}

public interface ITimelineJob<TTrack, TClip>
    where TTrack : unmanaged, IBlend<TClip>
    where TClip : unmanaged;

public interface IHook;
```

`ITimelineJob<TTrack,TClip>` identifies one operation kind. The operation declares exactly one accessible static `void Execute` whose first parameter is `in Frame<TTrack,TClip>`. Every remaining parameter is a required unmanaged `in` or `ref` slot.

```cs
public readonly struct DamageJob : ITimelineJob<DamageTrack, DamageClip>
{
    public static void Execute(
        in Frame<DamageTrack, DamageClip> frame,
        in Resistance resistance,
        ref Health health)
        => health = new(health.Value - frame.Direction * frame.Clip.Amount
            * frame.Track.Multiplier * resistance.Scale);
}
```

The parameter name and type identify a logical slot. Equal names and types join across jobs. If any use is `ref`, the generated schema column is writable. Reusing one name with incompatible types is a generation error. Alpha.3 rejects `out`, optional, managed, unscoped, and unsupported parameter forms during generation.

Hooks implement `IHook` and declare one accessible static `void Execute` beginning with `in TimelineFrame`, followed by the same slot grammar.

## Timeline authoring

```cs
public readonly partial struct Attack : ITimeline
{
    public static void Define(scoped Builder builder)
    {
        builder.Before<BeginAttack>();

        var opening = builder.Track(new AnimationTrack(1)).Use<AnimationJob>();
        var impact = builder.Track(new DamageTrack(2f)).Use<DamageJob>();
        var recovery = builder.Track(new AnimationTrack(3)).Use<AnimationJob>();

        builder.Clip(opening, new AnimationClip(2f, 1f), 0u, 20u);
        builder.Clip(impact, new DamageClip(10f), 5u, 6u);
        builder.Clip(recovery, new AnimationClip(-1f, 0f), 6u, 20u);

        builder.After<EndAttack>();
    }
}
```

`Define` is compile-time declarative input. It must have a block body composed of supported builder statements. Track settings, clip payloads, and bounds are bounded constructor, literal, or constant expressions. Clip bounds are half-open and satisfy `start < end`. A track must have at least one clip.

The builder surface is:

```cs
var track = builder.Track(in settings).Use<TJob>();
builder.Clip(in track, in clip, start, end);
builder.Before<THook>();
builder.After<THook>();
builder.Include<TTimeline>();
builder.Looping();
```

One include is supported per definition in alpha.3. Include cycles are rejected. An included loop mode and duration must remain compatible with the containing definition. A definition has at most 256 authored tracks and at most two simultaneously active clips on one track.

## Catalogs and schemas

```cs
public readonly struct DamageRows;
public readonly struct MixedRows;

public readonly partial struct Combat : ITimelineCatalog
{
    public static void Define(scoped CatalogBuilder builder)
    {
        builder.Schema<DamageRows>().Asset<DamageOnly>();
        builder.Schema<MixedRows>().Asset<Attack>().Asset<Recovery>();
    }
}
```

A schema marker is a unique, non-generic unmanaged type. Each schema lists the assets that its component columns can execute. A catalog assigns deterministic local route values: `Asset.None` is zero and up to 65,536 nonempty assets use generated positive `uint` values. State never carries a process-global registration ID.

For the catalog above, generation adds this conceptual surface:

```cs
public readonly partial struct Combat
{
    public const int AssetCount = 3;
    public static int StateBytes { get; }
    public static int StaticDataBytes { get; }

    public enum Asset : uint
    {
        None = 0,
        Attack = 1,
        DamageOnly = 2,
        Recovery = 3,
    }

    public struct State
    {
        public State(Asset asset, uint position = 0, long cycle = 0);
        public Asset Timeline { get; }
        public uint Position { get; }
        public long Cycle { get; }
    }

    public readonly struct Query
    {
        public DamageRowsQuery DamageRows(
            Span<State> states,
            ReadOnlySpan<Resistance> resistance,
            Span<Health> health);

        public MixedRowsQuery MixedRows(
            Span<State> states,
            Span<Pose> pose,
            ReadOnlySpan<Resistance> resistance,
            Span<Health> health);
    }

    public readonly ref struct MixedRowsQuery
    {
        public void Tick(uint gameTick, int delta = 1);
    }
}
```

Exact enum values and column order are generated facts and should be consumed by name. The query factory accepts one state column followed by the deduplicated component slots required by its assets. An input-only slot becomes `ReadOnlySpan<T>`; a slot written anywhere becomes `Span<T>`.

Query construction validates equal column lengths, current route membership, and overlapping storage whenever either alias is writable. The query borrows spans and retains no entity data after its ref-struct lifetime. Default query values are empty and `Tick` is a no-op.

Because state columns remain caller-writable, every nonzero `Tick` revalidates route membership before applying effects. Invalid schema routes, mismatched lengths, or prohibited aliases throw `ArgumentException` before callbacks. Timeline completion, empty routes, gaps, zero duration, and zero delta are ordinary no-ops and do not require a `Try` API.

## Tick

```cs
var states = new[]
{
    new Combat.State(Combat.Asset.Attack),
    new Combat.State(Combat.Asset.DamageOnly),
};
var query = new Combat.Query().MixedRows(states, pose, resistance, health);

query.Tick(200_000u);
query.Tick(200_001u, 4);
query.Tick(200_005u, -5);
```

For `Tick(G, N)`:

| Delta | Emitted game ticks | Final local movement |
| --- | --- | --- |
| `N > 0` | `G .. G + N - 1` | forward by each available frame |
| `N < 0` | `G - 1 .. G + N` | reverse by each available frame |
| `N = 0` | none | unchanged |

Game-tick arithmetic wraps explicitly as `uint`. The caller owns the game clock; it is not stored in `State`. Finite assets clamp independently at position zero or duration. A completed row stops contributing while other rows continue. A nonempty looping asset wraps and updates signed `Cycle` with explicit two's-complement overflow. Empty and `Asset.None` rows never emit.

Each requested step has three phases:

1. Select at most one frame for every row without invoking user code.
2. Execute the selected occurrence schedule by authored stage across compatible rows.
3. Commit each successfully selected row once after every stage.

This preserves A→B→A and opposing per-asset orders. Reverse movement visits the exact reversed occurrence slice. Rows are independent; jobs that mutate shared statics, follow shared pointers, or write another entity require a separately ordered domain.

If a user operation throws, the exception propagates. Effects already executed remain visible, and no selected state is committed for that step. The next call replaces internal pending selection before executing.

## Frames and flags

```cs
public readonly ref struct Frame<TTrack, TClip>
    where TTrack : unmanaged, IBlend<TClip>
    where TClip : unmanaged
{
    public ref readonly TTrack Track { get; }
    public ref readonly TClip Clip { get; }
    public uint GameTick { get; }
    public uint TimelineTick { get; }
    public long Cycle { get; }
    public ushort TrackIndex { get; }
    public FrameFlags Flags { get; }
    public int Direction { get; }
    public bool Has(FrameFlags flags);
}
```

`FrameFlags` is one byte containing `ClipStart`, `ClipEnd`, `TimelineStart`, `TimelineEnd`, `CompletedBefore`, `CompletedAfter`, `Looping`, and `Reverse`. `Direction` derives from `Reverse`; it consumes no field. `TimelineFrame` provides the same clock, cycle, flags, and direction facts to hooks without a track or clip.

One active clip is borrowed directly. Two active clips resolve into one callback-scoped value through `IBlend<TClip>.Blend`. The factor covers the overlap intersection and is `0.5f` for a one-frame overlap. Equal-start clips preserve authored order.

## Generation and packaging

The `Tl.CSharp` package installs `Tl.Runtime` and embeds the `Tl.Gen.CSharp` analyzer. The analyzer's compatible `Tl.Compiler.dll` is adjacent under `analyzers/dotnet/cs`. The standalone export tool carries its own compiler and Roslyn dependencies under `tools/net10.0/any`. These build assets never become application references.

Normal Roslyn and IDE design-time compilations run incremental generation. Explicit export runs the same reader and emitter:

```sh
dotnet msbuild -t:TlGenExport -p:Configuration=Release
```

The export is deterministic over sources, references, compiler options, and generator identity. It writes only owned output, preserves identical content, deletes stale owned artifacts, and reports cache hit or the exact miss reason.

The generated hot path allocates zero managed bytes after warmup. Static payload bytes, neutral schedule bytes, generated C# bytes, catalog state bytes, assemblies, NativeAOT images, and native text are separate measurements.
