# v1.0 alpha API contract

Status: signed-seek candidate contract, 2026-09-10. This document does not describe the released v0.6 API.

## Declaration

A top-level `public readonly partial struct` implements `ITimeline` and declares one `public static Define(scoped Builder builder)` method. A definition may contain different closed track and clip kinds.

```cs
using Tl;

public readonly record struct Pose(float X, float Y);
public readonly record struct AnimationSettings(float Weight);
public readonly record struct AnimationClip(float X, float Y);
public readonly record struct Health(float Value);
public readonly record struct DamageSettings(float Multiplier);
public readonly record struct DamageClip(float Amount);

public readonly struct AnimationTrack : ITrack<AnimationClip>
{
    public void Blend(in AnimationClip first, in AnimationClip second, float factor, out AnimationClip result)
        => result = new(
            first.X + (second.X - first.X) * factor,
            first.Y + (second.Y - first.Y) * factor);

    public static void Seek(
        in Frame<AnimationTrack, AnimationClip> frame,
        in Pose currentPose,
        in AnimationSettings animationSettings,
        out Pose nextPose)
        => nextPose = new(
            currentPose.X + frame.Direction * frame.Clip.X * animationSettings.Weight,
            currentPose.Y + frame.Direction * frame.Clip.Y * animationSettings.Weight);
}

public readonly struct DamageTrack : ITrack<DamageClip>
{
    public void Blend(in DamageClip first, in DamageClip second, float factor, out DamageClip result)
        => result = new(first.Amount + (second.Amount - first.Amount) * factor);

    public static void Seek(
        in Frame<DamageTrack, DamageClip> frame,
        in Health currentHealth,
        in DamageSettings damageSettings,
        out Health nextHealth)
        => nextHealth = new(
            currentHealth.Value - frame.Direction * frame.Clip.Amount * damageSettings.Multiplier);
}

public readonly partial struct Attack : ITimeline
{
    public static void Define(scoped Builder builder)
    {
        var animation = builder.Track(new AnimationTrack());
        var damage = builder.Track(new DamageTrack());
        builder.Clip(animation, new AnimationClip(2f, 1f), 0u, 40u);
        builder.Clip(animation, new AnimationClip(6f, 3f), 20u, 60u);
        builder.Clip(damage, new DamageClip(10f), 10u, 11u);
        builder.Clip(damage, new DamageClip(20f), 40u, 41u);
    }
}
```

The generator interprets the supported declaration syntax without executing `Define`. `TrackRef<TTrack>` carries its track kind and builder ownership. Invalid windows, mismatched clip types, foreign handles, unsupported statements, ambiguous component slots, and more than two overlapping clips on one track are build diagnostics.

`ITrack<TClip>` combines the blend contract with exactly one public static `Seek` operation. Its first parameter is `in Frame<TTrack,TClip>`. Every remaining parameter is an explicit unmanaged `in`, `ref`, or `out` component slot. The generator uses exact parameter identity, type, and access mode; it does not use reflection, boxing, implicit conversion, an object array, or handwritten attributes.

## Frame

| Member | Contract |
| --- | --- |
| `Track` | Borrowed read-only reference to the authored track value |
| `Clip` | Borrowed read-only reference to the resolved clip value |
| `GameTick` | Simulation tick for this executed frame |
| `TimelineTick` | Local tick within the definition duration |
| `Cycle` | Signed loop cycle; zero for finite definitions |
| `TrackIndex` | Stable 16-bit authored track identity |
| `Flags` | Independent clip, timeline, completion, loop, and reverse facts |
| `Direction` | `1` unless `FrameFlags.Reverse` is set, then `-1` |

`Frame<TTrack,TClip>` is a readonly ref struct scoped to one operation call. It has no ordinal or active-count field. A resolved blend remains valid until the operation returns.

`FrameFlags` contains `ClipStart`, `ClipEnd`, `TimelineStart`, `TimelineEnd`, `CompletedBefore`, `CompletedAfter`, `Looping`, and `Reverse`. Several boundary facts may be true on the same frame. A one-frame clip has both clip boundary bits. A one-frame timeline has both timeline boundary bits.

## Generated data

The generator emits `Attack.Data` for the typed facade and `Attack.DynamicData` for the dynamic facade. Both are stack-only ref structs containing borrowed references. They copy no component payload and cannot survive an async suspension, ECS structural change, or their caller scope.

```cs
var currentPose = new Pose(0f, 0f);
var animationSettings = new AnimationSettings(1f);
var currentHealth = new Health(100f);
var damageSettings = new DamageSettings(1f);
var nextPose = currentPose;
var nextHealth = currentHealth;
var playback = Attack.Start(50_000u);
var data = new Attack.Data(
    ref playback,
    in animationSettings,
    in currentHealth,
    in currentPose,
    in damageSettings,
    ref nextHealth,
    ref nextPose);

if (!Attack.TrySeek(ref data, 11))
    return;

if (!Attack.TrySeek(ref data, -6))
    return;
```

The playback reference is part of the generated data because success updates the caller-owned value directly. An `in` slot is a read-only alias through that operation; another writable alias can still change its storage. A `ref` slot aliases caller storage. An `out` operation parameter maps to initialized writable outer storage so gaps and rejected operations preserve it.

No fixed arity exists. Different operations in the same definition contribute to the union of required slots. Repeated component types remain distinct when parameter identities differ. A missing, ambiguous, incorrectly typed, or incorrectly permissioned dynamic context rejects before effects.

## Signed seek

`Start(gameTick)` creates a started playback at timeline position zero. The argument anchors simulation time; it does not seek into the timeline.

For a playback at position `P` and game tick `G`:

- `TrySeek(ref data, d)` with `d > 0` executes positions `P` through `P + d - 1` in ascending order, then stores position `P + d` and game tick `G + d`.
- `TrySeek(ref data, d)` with `d < 0` executes positions `P - 1` through `P + d` in descending order, then stores position `P + d` and game tick `G + d`.
- `TrySeek(ref data, 0)` succeeds without callbacks and preserves playback and components.

Every crossed local frame is executed. A multi-frame delta is semantically equal to repeated signed unit seeks in the same direction, including track order, hook order, frame flags, blending, and floating-point evaluation order.

Finite definitions accept positions from zero through `Duration`. A seek whose target leaves that closed boundary rejects before effects. Empty finite definitions therefore accept only delta zero. Looping nonempty definitions normalize every executed position to `TimelineTick` and `Cycle` without restricting signed position to one duration. Game-tick arithmetic is unchecked `uint` arithmetic, matching simulation tick wrap.

One active clip is borrowed directly. Two active clips resolve once through `Blend`; its factor uses the clips' intersection and is `0.5f` for a one-frame intersection. Active tracks execute in stable authored order. Gaps execute hooks but no track operation.

Forward execution runs Before hooks, tracks, then After hooks. Reverse execution is the structural inverse: After hooks in reverse order, tracks in reverse order, then Before hooks in reverse order. Track code uses `Frame.Direction` and boundary flags to define its reversible effect. Consumer exceptions propagate and preserve the already-executed prefix.

## Typed and dynamic facades

Use the typed facade when the definition is known at the call site:

```cs
var playback = Attack.Start(10u);
var data = new Attack.Data(
    ref playback,
    in animationSettings,
    in currentHealth,
    in currentPose,
    in damageSettings,
    ref nextHealth,
    ref nextPose);

if (!Attack.TrySeek(ref data, 1))
    return;

if (Attack.TryStop(in playback, out var stopped))
    playback = stopped;
```

The typed facade has no runtime ID lookup. `Playback<Attack>` encodes the timeline identity in its type.

Use the dynamic facade when the ID is selected at runtime:

```cs
ushort id = Attack.Id;

if (!Timeline.TryStart(id, 10u, out var playback))
    return;

var data = new Attack.DynamicData(
    ref playback,
    in animationSettings,
    in currentHealth,
    in currentPose,
    in damageSettings,
    ref nextHealth,
    ref nextPose);

if (!Timeline.TrySeek(id, ref data, -1))
    return;

if (Timeline.TryStop(id, in playback, out var stopped))
    playback = stopped;
```

The dynamic path validates live ID, playback owner, generated schema route, lifecycle, current position, arithmetic, and target position before user effects. On engine rejection it preserves playback and components. `TryStart` returns default playback for an invalid ID. `TryStop` is idempotent for an already-stopped playback with the same owner. User exceptions are not converted to `false` and are not rolled back.

## Hooks and composition

Hooks use direction-specific methods because they have no frame parameter. Their component slots join the generated data schema.

```cs
public struct Analytics
{
    public int Samples;
}

public readonly struct CountFrames : IHook
{
    public static void Forward(ref Analytics analytics)
        => analytics.Samples++;

    public static void Backward(ref Analytics analytics)
        => analytics.Samples--;
}

public readonly partial struct ObservedAttack : ITimeline
{
    public static void Define(scoped Builder builder)
    {
        builder.Before<CountFrames>();
        builder.Include<Attack>();
    }
}
```

`Include<TTimeline>` requires a source-visible definition in the same compilation. Graphs are cycle-checked and flattened in deterministic authored order. Each including definition receives its own typed facade, schema, and optional dynamic ID.

## Discovery, incrementality, and reports

Installing `Tl.CSharp` is sufficient. There is no runtime `Build`, `Compile`, `InMemory`, `Bind`, destruction operation, manual source item, or interpreted fallback. Normal and IDE design-time compilation run the same pass; editor scheduling determines when generated types refresh.

The syntax provider filters type declarations with base lists, confirms the exact `Tl.ITimeline` symbol semantically, and lowers each candidate to structural data without retaining syntax nodes, semantic models, symbols, or compilations. Compilation-wide collection owns includes, schemas, modules, and routes. Unchanged and unrelated edits reuse equal results; declaration, option, and reference changes invalidate the affected steps. The compiler owns normal generated sources. Run the explicit `TlGenExport` MSBuild target for deterministic source files, a content cache, and a report under `obj/<configuration>/<tfm>/TlGenCompile`.

Generated timelines expose `Duration`, `Loops`, `TrackCount`, `ClipCount`, `RegionCount`, and `StaticDataBytes`. `Id` is lazily registered when the dynamic facade is used. `Timeline.RegistryRetainedBytes` reports actual process-wide unmanaged registry allocation.

## Capacity and lifetime

- Dynamic IDs cover `0..65,535`; a valid bit distinguishes slot zero from absence.
- A generated module contains at most 256 dynamic routes.
- A definition contains at most 256 closed track/clip kinds and 65,536 track instances.
- Timeline, registry, and generated payload data are immutable after publication.
- Warm typed and dynamic seek allocate zero managed bytes.
- Caller-owned writable storage requires the caller's synchronization.
- Contexts cannot be retained, recursively reused with the same writable aliases, or moved across asynchronous or structural boundaries.
- NativeAOT is verified for the C# runtime. C11 and Unity/Burst have separate ABIs, packages, and qualification gates.

See [semantics](semantics.md) for the execution law and [migration](v1.0-alpha-migration.md) for removed APIs.
