# v1.0.0-alpha.3

Alpha.3 replaces per-timeline playback facades and runtime IDs with generated catalog queries over borrowed component columns. One timeline can contain heterogeneous track and clip pairs. Each authored track binds one typed operation, and every row retains independent asset, position, and loop cycle while sharing the caller's game clock.

## Public model

```cs
public readonly struct DamageJob : ITimelineJob<DamageTrack, DamageClip>
{
    public static void Execute(
        in Frame<DamageTrack, DamageClip> frame,
        in Resistance resistance,
        ref Health health)
        => health = new(health.Value - frame.Direction * frame.Clip.Amount
            * frame.Track.Multiplier * resistance.Scale);
}

public readonly partial struct Attack : ITimeline
{
    public static void Define(scoped Builder builder)
    {
        var damage = builder.Track(new DamageTrack(2f)).Use<DamageJob>();
        builder.Clip(damage, new DamageClip(10f), 5u, 6u);
    }
}

public readonly struct CombatRows;

public readonly partial struct Combat : ITimelineCatalog
{
    public static void Define(scoped CatalogBuilder builder)
        => builder.Schema<CombatRows>().Asset<Attack>();
}

var states = new[] { new Combat.State(Combat.Asset.Attack) };
var query = new Combat.Query().CombatRows(states, resistance, health);
query.Tick(200_000u, 3);
query.Tick(200_003u, -3);
```

Normal Roslyn and supporting IDE builds generate timelines and catalogs automatically. The execution API has no `Build`, `Compile`, `InMemory`, `Bind`, registration ID, `Start`, `Stop`, `TrySeek`, or per-tick failure value.

## Semantics

- A requested step selects each row without effects, executes typed stages in authored order, then commits each selected row once.
- Reverse movement executes the exact reversed occurrence order.
- `Tick(G,+N)` emits `G..G+N-1`; `Tick(G,-N)` emits `G-1..G-N`.
- Finite assets clamp independently. Empty routes, gaps, empty definitions, completion, and zero delta are no-ops.
- Nonempty loops use unsigned local position and signed cycle with explicit wrapping arithmetic.
- One active clip is borrowed; two active clips resolve through `Blend` into one frame.
- Jobs borrow unmanaged `in` and `ref` columns. Alpha.3 rejects `out`.
- Schema construction rejects mismatched lengths, invalid routes, and prohibited writable aliases before effects.
- A user exception preserves its executed effect prefix and prevents commit for that selected step.

See the [complete API](v1.0-alpha-api.md) and [execution semantics](semantics.md).

## Packages

The GitHub prerelease contains five runtime/build packages, three symbol packages, a deterministic Unity UPM archive, a NativeAOT smoke archive, a generation report, a release manifest, and SHA-256 checksums. NuGet publication is disabled; install the `.nupkg` files from a local source.

`Tl.CSharp` is the recommended C# install. It depends on `Tl.Runtime` at application runtime and embeds `Tl.Gen.CSharp.dll` plus the compatible `Tl.Compiler.dll` as build-only analyzer/tool assets. Package-only JIT and NativeAOT receipts prove those toolchain assemblies do not enter application output.

The UPM package contains the Unity runtime boundary only. A package-only .NET authoring project materializes deterministic Unity-compatible C# before Unity compilation; compiler and Roslyn assets stay outside the player graph.

`Tl.Gen.C` retains its qualified C ABI v2 backend. It does not yet emit alpha.3 heterogeneous catalogs.
