# Tl for Unity

The Unity adapter for the data-authored system lives in the extracted [IAFahim/tl.unity](https://github.com/IAFahim/tl.unity) repository, published under the MIT license decided in [issue #64](https://github.com/IAFahim/tl/issues/64). This repository ships no UPM package.

The v1.0.0-alpha.3 Unity package and its qualification receipts are historical: see [docs/alpha3/unity-execution.md](alpha3/unity-execution.md) and the [v1.0.0-alpha.3 tag](https://github.com/IAFahim/tl/releases/tag/v1.0.0-alpha.3).
