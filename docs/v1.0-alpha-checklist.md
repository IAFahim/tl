# v1.0.0-alpha.1 completion checklist

Base: v0.6.0 at `f3f91fe`. Target: `v1.0.0-alpha.1`.

This checklist records the release boundary. Completed items have executable evidence. Deferred items are named alpha limits rather than unfinished claims. The full design reasoning and future optimization matrix remain in [plan.md](../plan.md).

## Public model

- [x] Replace homogeneous `Timeline<TTrack,TClip>` with non-generic `ITimeline` declarations and `ushort` runtime IDs.
- [x] Allow different closed track/clip kinds inside one timeline.
- [x] Replace `Tracks<TTrack,TClip>` consumption with one `Frame<TTrack,TClip>` callback per active authored track.
- [x] Keep `Frame` to `Track`, resolved `Clip`, effective `Tick`, `State`, and stable 16-bit `TrackIndex`.
- [x] Remove ordinal and active-count data from the public frame.
- [x] Infer any finite callback parameter list from explicit `in`, `ref`, and `out` modes.
- [x] Generate separate stack-only `Input` and `Output` borrowed contexts.
- [x] Preserve writable caller aliases, including object fields and array elements through compacting GC.
- [x] Provide scalar and span `TryForward` and `TryBackward`, `TryStart`, idempotent `TryStop`, and `Timeline.All[id]`.
- [x] Make failure total: invalid ID, owner, lifecycle, tick, or schema returns `false` before user effects.
- [x] Authenticate playback ownership with a 12-byte unmanaged `Playback`.

## Authoring and composition

- [x] Discover normal project compile items automatically after a package reference.
- [x] Remove `Build`, `Compile`, `InMemory`, `Bind`, and manual timeline source items.
- [x] Infer track and clip types from `builder.Track` and `builder.Clip`.
- [x] Validate top-level partial timeline declarations, callback shapes, constant payloads, windows, ownership, and overlap bounds.
- [x] Support explicit `Before<THook>` and `After<THook>` phases.
- [x] Support one nested `Include<TTimeline>` chain with deterministic outer-before, included work, outer-after order.
- [x] Diagnose cycles, multiple includes, invalid hooks, missing callbacks, ambiguous slots, and unsupported authoring.
- [x] Preserve authored effect order, including equal-start clips.
- [x] Generate exact-schema direct routes and compatible alternate-schema routes.
- [x] Reject missing or permission-incompatible alternate contexts before effects.
- [x] Keep included definitions and compatible routes limited to definitions visible in the same compilation.
- [x] Document that declarations produced by another source generator cannot feed this pre-compilation pass.

## Generated execution

- [x] Emit scalar kernels without creating a one-element span.
- [x] Emit direct per-region basic blocks with fixed track count, payloads, state rules, and blend rules.
- [x] Inline exact-schema public dispatch through the generated context protocol.
- [x] Keep registry, route lookup, compatibility router, and callback calls out of the exact hot body.
- [x] Hoist validation and routing once for batch calls.
- [x] Keep region search logarithmic for random seeking and branch-light for small definitions.
- [x] Allocate 0 managed bytes after warmup in scalar and batch playback.
- [x] Use no reflection, boxing, delegates, runtime authoring graph, binding table, or managed retained timeline data.
- [x] Store the compact registry and metadata in unmanaged memory.
- [x] Cover all 65,536 timeline IDs without reuse and all 256 module slots.
- [x] Enforce at most 256 closed track/clip kinds and 65,536 authored track instances per definition.
- [x] Preserve deterministic output and timestamps on a cache hit.
- [x] Invalidate generation for source, define, compiler, option, reference, or generator identity changes.

## Correctness gates

- [x] Release build has zero warnings and zero errors.
- [x] Core public API approval passes.
- [x] All generator unit and semantic tests pass.
- [x] Same-compilation compatible routing, missing-schema rejection, include order, hook order, and diagnostics pass.
- [x] Forward/backward, looping, gaps, blends, one-tick clips, empty batches, cycle overflow, and lifecycle receipts pass.
- [x] Managed byrefs remain valid through forced compacting GC.
- [x] Parallel ID and module registration produce unique values.
- [x] ID and module capacity boundaries and overflow rejection pass.
- [x] JIT smoke, mixed sample, and independent benchmark oracle pass.
- [x] NativeAOT smoke, ID capacity, and module capacity pass with identical receipts.
- [x] Generated input/output survive a fresh package-only consumer build.

## Performance gates

- [x] Measure complete public scalar, indexed, public batch-8, indexed batch-8, and handwritten scalar-oracle arms.
- [x] Consume complete playback and output receipts so work cannot be removed.
- [x] Verify every benchmark arm against the same independent expected receipt before timing.
- [x] Measure sequential and random tick distributions separately.
- [x] Run 65,536 operations per invocation, 16 warmups, 12 measured iterations, and 250 ms iterations.
- [x] Retain three independent final public runs and one complete direct/public/indexed run.
- [x] Reach the target on the reference machine: Sum 1.382 ns/tick and Combat 2.239 ns/tick public sequential scalar.
- [x] Reach the target for batch-8: Sum 1.384 ns/tick and Combat 2.033 ns/tick.
- [x] Report random costs separately: 4.854–6.974 ns/tick across public scalar and batch.
- [x] Verify 0 B allocation for every measured arm.

- [x] Record that process-priority elevation failed and fixed-frequency/affinity controls were unavailable.
- [x] Record that `perf` hardware counters were unavailable and make no NativeAOT timing claim.
