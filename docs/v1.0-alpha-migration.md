# Migrating from v0.6

Install `Tl.CSharp` at the current prerelease version and remove manual timeline source items. Its only package dependency is `Tl.Runtime`; it embeds the `Tl.Gen.CSharp` analyzer and explicit export tool. `Tl.Compiler` and `Tl.Gen.C` remain separate packages. Toolchains that do not use the one-install package can reference `Tl.Runtime` and `Tl.Gen.CSharp` separately. Normal and IDE builds discover ordinary C# compile items through Roslyn incremental generation. Use `dotnet msbuild -t:TlGenExport` only when standalone generated files and a report are required.

`TimelinePlan.Validate()` is an additive compiler API for backend and tooling authors. It returns the format-v1 validated plan and deterministic region schedule; existing `TimelinePlan`, `TrackPlan`, and `ClipPlan` constructors keep their shapes. The C ABI remains version 2 because this compiler-only extraction does not change generated C bytes or native layout. The C# generator continues to use its private language-specific model in this release.

## Declare one heterogeneous definition

Replace generic timeline declarations and runtime authoring with one non-generic partial declaration:

```cs
public readonly partial struct Attack : ITimeline
{
    public static void Define(scoped Builder builder)
    {
        var animation = builder.Track(new AnimationTrack());
        var damage = builder.Track(new DamageTrack());
        builder.Clip(animation, new AnimationClip(2f, 1f), 0u, 40u);
        builder.Clip(damage, new DamageClip(10f), 10u, 11u);
    }
}
```

`Build`, `Compile`, `InMemory`, `Bind`, manual compiled source lists, runtime authoring graphs, and interpreted fallback are absent from the generated path.

## Replace directional track operations

Each track implements `ITrack<TClip>`, retains `Blend`, and declares one signed `Seek` operation:

```cs
public readonly struct DamageTrack : ITrack<DamageClip>
{
    public void Blend(in DamageClip first, in DamageClip second, float factor, out DamageClip result)
        => result = new(first.Amount + (second.Amount - first.Amount) * factor);

    public static void Seek(
        in Frame<DamageTrack, DamageClip> frame,
        in Health currentHealth,
        out Health nextHealth)
        => nextHealth = new(currentHealth.Value - frame.Direction * frame.Clip.Amount);
}
```

`Frame.Direction` is `1` or `-1`. Independent `FrameFlags` expose clip, timeline, completion, loop, and reverse boundaries. The frame also carries `GameTick`, `TimelineTick`, signed `Cycle`, and `TrackIndex`.

## Replace destination sampling with signed replay

Construct the generated borrowed data once for the current component references, then seek by a signed delta:

```cs
var playback = Attack.Start(gameTick);
var data = new Attack.Data(
    ref playback,
    in animationSettings,
    in currentHealth,
    in currentPose,
    in damageSettings,
    ref nextHealth,
    ref nextPose);

if (!Attack.TrySeek(ref data, 5))
    return;

if (!Attack.TrySeek(ref data, -5))
    return;
```

`Start(gameTick)` anchors simulation time at timeline position zero. A positive delta executes each crossed local frame forward; a negative delta executes each crossed local frame backward. A delta of five is semantically equal to five calls with delta one. It does not sample only the destination.

`Attack.Data` replaces separate input and output wrappers. It contains borrowed references: callback `in` parameters become read-only references, and callback `ref` or `out` parameters become writable references. No component payload is copied into the context.

## Runtime-selected IDs

Use the generated dynamic data type when the definition is selected by ID:

```cs
ushort id = Attack.Id;

if (!Timeline.TryStart(id, gameTick, out var playback))
    return;

var data = new Attack.DynamicData(
    ref playback,
    in animationSettings,
    in currentHealth,
    in currentPose,
    in damageSettings,
    ref nextHealth,
    ref nextPose);

if (!Timeline.TrySeek(id, ref data, delta))
    return;
```

The typed path avoids registry lookup. The dynamic path checks ID ownership and schema before effects. The old indexed facade is removed; an ID alone cannot manufacture the component references required by an arbitrary timeline.

## ABI changes

`Playback` and `Playback<TTimeline>` are 16-byte readonly sequential values. Both carry signed 64-bit `Position` and 32-bit `GameTick`; dynamic playback also carries its 16-bit owner. `Frame<TTrack,TClip>` is a readonly ref struct borrowing track and clip payloads. On x64 its current verified layout is 40 bytes, but it remains a managed C# ABI rather than the portable C or Unity ABI.

The complete working C# example is [samples/Mixed/Program.cs](../samples/Mixed/Program.cs). The exact execution law is [docs/semantics.md](semantics.md).
