# Migrating from v0.6

Install `Tl.CSharp` at `1.0.0-alpha.2`. It brings in `Tl.Runtime` and keeps `Tl.Gen.CSharp`, `Tl.Compiler`, Roslyn, and backend tooling in the build process. Remove every `TlCompileTimeline` item. Normal compile items are discovered automatically.

Replace a homogeneous declaration:

```cs
public readonly partial struct Attack : ITimeline<AttackTrack, AttackClip>
{
    public static void Define(scoped TimelineBuilder<AttackTrack, AttackClip> builder) { }
}
```

with the non-generic declaration:

```cs
public readonly partial struct Attack : ITimeline
{
    public static void Define(scoped Builder builder)
    {
        var animation = builder.Track(new AnimationTrack());
        var damage = builder.Track(new DamageTrack());
        builder.Clip(in animation, new AnimationClip(2f, 1f), 0u, 40u);
        builder.Clip(in damage, new DamageClip(10f), 10u, 11u);
    }
}
```

Move consumer behavior onto each track type. The first parameter identifies the exact frame kind. Remaining parameters declare the generated context.

```cs
public readonly struct DamageTrack : ITrack<DamageClip>
{
    public void Blend(in DamageClip first, in DamageClip second, float factor, out DamageClip result)
        => result = new(first.Amount + (second.Amount - first.Amount) * factor);

    public static void Forward(in Frame<DamageTrack, DamageClip> frame, in Health current, out Health next)
        => next = new(current.Value - frame.Clip.Amount);

    public static void Backward(in Frame<DamageTrack, DamageClip> frame, in Health current, out Health next)
        => next = new(current.Value + frame.Clip.Amount);
}
```

Replace direct generated methods or runtime binding with the uniform ID surface:

```cs
var input = new Attack.Input(current: in currentHealth);
var output = new Attack.Output(next: ref nextHealth);

if (Timeline.TryStart(Attack.Id, out var playback)
    && Timeline.TryForward(Attack.Id, in playback, tick, in input, ref output, out var nextPlayback))
    playback = nextPlayback;
```

`Playback` is now 12 bytes because it carries a 16-bit owner while retaining the 32-bit tick, 16-bit cycle count, and lifecycle flags. This prevents state from one timeline being accepted by another. Compiled IDs cannot be destroyed or reused.

`Frame` omits ordinal and active count. When behavior needs begin/end aggregation, declare an explicit hook or model that aggregation as its own track. This keeps ordinary work free of an unrelated counting prepass.

The complete working example is [samples/Mixed/Program.cs](../samples/Mixed/Program.cs).
