# Migrating from v1.0.0-alpha.2 to alpha.3

Alpha.3 replaces per-timeline signed-seek facades and the dynamic registry with generated catalog queries over component columns. Recompile every consumer; this is both a source and binary break.

## Package

```xml
<PackageReference Include="Tl.CSharp" Version="1.0.0-alpha.3" />
```

`Tl.CSharp` carries the build-only generator and depends on `Tl.Runtime`. The analyzer package now includes its exact `Tl.Compiler` dependency beside the analyzer, while the export tool carries the net10 compiler under `tools`. Compiler and Roslyn assemblies remain absent from JIT and NativeAOT application output.

## Split track data from behavior

Alpha.2 placed `Seek` on `ITrack<TClip>`:

```cs
public readonly struct DamageTrack : ITrack<DamageClip>
{
    public void Blend(in DamageClip first, in DamageClip second, float factor, out DamageClip result)
        => result = new(first.Amount + (second.Amount - first.Amount) * factor);

    public static void Seek(
        in Frame<DamageTrack, DamageClip> frame,
        in Resistance resistance,
        ref Health health)
        => health = new(health.Value - frame.Direction * frame.Clip.Amount * resistance.Scale);
}
```

Alpha.3 keeps immutable track settings on `IBlend<TClip>` and moves behavior into a named job:

```cs
public readonly struct DamageTrack : IBlend<DamageClip>
{
    public void Blend(in DamageClip first, in DamageClip second, float factor, out DamageClip result)
        => result = new(first.Amount + (second.Amount - first.Amount) * factor);
}

public readonly struct DamageJob : ITimelineJob<DamageTrack, DamageClip>
{
    public static void Execute(
        in Frame<DamageTrack, DamageClip> frame,
        in Resistance resistance,
        ref Health health)
        => health = new(health.Value - frame.Direction * frame.Clip.Amount * resistance.Scale);
}
```

This allows many authored tracks with the same pair to share one operation kind, while one timeline may contain unrelated track, clip, and job types.

`Execute` supports required unmanaged `in` and `ref` component parameters. Rename `out` parameters to `ref` and initialize their columns before calling the query. A skipped track or row leaves that value unchanged; no generated operation invents an output for work that did not occur.

## Bind every track to a job

Alpha.2:

```cs
var damage = builder.Track(new DamageTrack());
builder.Clip(damage, new DamageClip(10f), 0u, 10u);
```

Alpha.3:

```cs
var damage = builder.Track(new DamageTrack()).Use<DamageJob>();
builder.Clip(damage, new DamageClip(10f), 0u, 10u);
```

No runtime `Bind` operation is involved. `Use<TJob>()` is a compile-time declaration checked against the track and clip pair.

## Add a catalog schema

Catalogs replace process-global IDs and tell the generator which assets may inhabit one component layout.

```cs
public readonly struct CombatRows;

public readonly partial struct Combat : ITimelineCatalog
{
    public static void Define(scoped CatalogBuilder builder)
    {
        builder.Schema<CombatRows>()
            .Asset<Attack>()
            .Asset<Recovery>();
    }
}
```

Each schema marker has one generated query factory. Its asset list is closed and validated before effects. Use another schema when its component columns differ.

## Replace playback and signed seek

Alpha.2:

```cs
var playback = Attack.Start(gameTick);
var data = new Attack.Data(
    ref playback,
    in resistance,
    ref health);

if (!Attack.TrySeek(ref data, delta))
    return;
```

Alpha.3:

```cs
var states = new[] { new Combat.State(Combat.Asset.Attack) };
var resistance = new[] { new Resistance(1f) };
var health = new[] { new Health(100f) };
var query = new Combat.Query().CombatRows(states, resistance, health);

query.Tick(gameTick, delta);
```

There is no `Start`, `Stop`, `TrySeek`, typed playback, dynamic playback, `Data`, `DynamicData`, `Timeline.TryStart`, or `Timeline.TrySeek`. Constructing `State` selects an asset and optionally supplies its local position and cycle. Default state and `Asset.None` are valid empty rows.

Completion is total: a finite row at either boundary contributes no work in that direction. Other rows continue. `Tick` throws only for schema misuse such as an invalid mutable route or overlapping writable columns. A user operation exception still propagates.

The clock law changes shape but retains signed replay:

```cs
query.Tick(200_000u, 3);
query.Tick(200_003u, -3);
```

The first call emits game ticks 200,000 through 200,002. The second emits 200,002 through 200,000 while reversing occurrence order. `State` stores local position and signed loop cycle, not game time.

## Replace one-object calls with columns

Alpha.2 borrowed fields through one generated ref struct. Alpha.3 borrows homogeneous columns so one typed operation stage can process every compatible entity:

```cs
var states = new Combat.State[10_000];
var poses = new Pose[states.Length];
var resistance = new Resistance[states.Length];
var health = new Health[states.Length];

for (var row = 0; row < states.Length; row++)
    states[row] = new Combat.State(
        (row & 1) == 0 ? Combat.Asset.Attack : Combat.Asset.Recovery);

var query = new Combat.Query().CombatRows(states, poses, resistance, health);
query.Tick(gameTick);
```

All columns have equal length. Input-only slots are `ReadOnlySpan<T>` and writable slots are `Span<T>`. The query rejects overlap involving writable storage. It stores only borrowed spans and cannot escape its ref-struct lifetime.

## Ordering change

Alpha.3 treats authored occurrences as the semantic program. For one simulation step it selects all rows, executes stage zero across compatible rows, then stage one, and continues until the longest selected schedule is complete. It commits each row once afterward.

This preserves timelines such as A→B→A and permits another asset to use B→A. Reverse movement uses the exact reversed occurrence order. Do not replace this with global grouping by job type; a type mask cannot encode occurrence order.

## Generated identity and reporting

Replace `Attack.Id` with `Combat.Asset.Attack`. The enum value is catalog-local; persist a stable application asset key and resolve it to the generated enum at your import boundary.

Replace registry memory counters with generated facts:

```cs
Console.WriteLine(Combat.AssetCount);
Console.WriteLine(Combat.StateBytes);
Console.WriteLine(Combat.StaticDataBytes);
Console.WriteLine(Attack.TrackCount);
Console.WriteLine(Attack.ClipCount);
Console.WriteLine(Attack.MaxStageCount);
Console.WriteLine(Attack.StaticDataBytes);
```

`dotnet msbuild -t:TlGenExport -p:Configuration=Release` emits standalone generated source plus a deterministic manifest and report. Normal and IDE compilation remains automatic.

## Removed alpha.2 concepts

- `ITrack<TClip>` and static `Seek` on the track
- `Playback` and `Playback<TTimeline>`
- `Start`, `Stop`, `TrySeek`, and direction-specific entry points
- `Data` and `DynamicData`
- runtime `ushort` IDs and global registry
- `Timeline.TryStart`, `Timeline.TrySeek`, and `Timeline.TryStop`
- runtime `Build`, `Compile`, `InMemory`, `Bind`, and destruction
- destination sampling and silent interpreted fallback

The complete alpha.3 example is [samples/Mixed/Program.cs](../samples/Mixed/Program.cs). Exact behavior is specified in [semantics.md](semantics.md).
